# 05 — MVP SCOPE

The MVP is the smallest product that produces: (1) first-session emotional WOW, (2) daily return, (3) subscription conversion, (4) personalization that improves over time. Everything else waits.

## MVP / V1 (ships at launch)

| Feature                                                                                                                                                                                                           | Why it's in                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Conversational onboarding (9–11 screens, edit-guard, reflections)                                                                                                                                                 | Sets up the wow; captures the memory seed                                     |
| **Future-Self Letter** (text+audio, pre-paywall)                                                                                                                                                                  | THE wow; drives trial start                                                   |
| Daily personalized audio **Moment** (60–120s) + player (play/pause, scrub, ±15s, speed, Read mode)                                                                                                                | Core daily value; proven mechanic                                             |
| "Coming for you" (2–3 forming previews with arrival dates)                                                                                                                                                        | Return anticipation                                                           |
| **Manifest Anything** on-demand moment (typed desire → moment), limited/week                                                                                                                                      | Signature capability + cost control                                           |
| Refine feedback (more realistic / softer / more ambitious → regenerates + teaches memory)                                                                                                                         | Personalization improves over time                                            |
| **Affirmation Studio**: 1 daily generated affirmation + guided-question generation (goal → feeling → phrasing style) + light technique framing (identity phrasing, present tense; "try this with the 369 method") | Founder's key focus; daily habit; share engine                                |
| Affirmation cards: save to collection, share-as-image                                                                                                                                                             | Organic growth loop                                                           |
| **Gratitude (minimal)**: one line/day, AI-personalized prompt, gentle weekday dots, entries feed memory                                                                                                           | Founder's key focus; retention glue; cheap (Stella's version is a text field) |
| **Living Memory v1**: profile (basics, dream, people, lifestyle, struggle, exact phrases) + evolving memories from entries/refines + **"What Aura Knows"** transparency screen + Never-Include list               | The moat; trust feature                                                       |
| Callbacks v1: name/word echoes in all generations + Day-7 milestone letter                                                                                                                                        | First micro-wows                                                              |
| Notifications: moment arrival at chosen time (set in onboarding), optional affirmation nudge; companion voice                                                                                                     | 3x retention lever                                                            |
| Paywall: hard-soft hybrid after the Letter; annual pre-selected + weekly; transparent pricing; limited free tier (1 moment + 1 affirmation + gratitude, no on-demand, no export)                                  | Conversion + trust                                                            |
| Settings: subscription mgmt, support, rate/share, legal, delete account & data                                                                                                                                    | Store compliance + trust                                                      |
| Analytics per 17                                                                                                                                                                                                  | Learn or die                                                                  |

## V1.1 (weeks after launch — fast follows)

- Milestone letters D30/D100; anniversary echo; automated 3-week callbacks.
- **Learn library**: full technique cards (369, scripting, visualization, gratitude science, phrasing science) with "practice now" links into the studio. (V1 embeds only inline snippets.)
- Custom affirmations: write your own + "want me to say it the way your future self would?" rewrite.
- Second voice option; localized pricing tests; annual-plan paywall optimization.

## V2

- Own-voice affirmations (record/clone — Innertune thesis; consent flow per 18).
- Home/lock-screen widget (native code; Aya's proven surface).
- Ambient soundscapes under narration (Stella's mixer, simplified).
- Vision Board with pinned audio moments ("hear this dream"); mark-as-manifested celebration.
- Gratitude weaving fully automated (entries appear inside future moments).
- Read-aloud affirmation practice (speech recognition).

## LATER / EXPERIMENT

- Open companion chat (explicitly NOT a chatbot at V1 — big cost + scope risk).
- Faith-based sister mode; evidence-based "skeptic mode" toggle; men's variant.
- Community/success-story feed; accountability buddies; referral loop.
- Apple Watch; Android; localization (JP/Nordics); B2B/creator partnerships.
- AI vision-board image generation; dream/emotion analysis.

## Explicit CUTS from V1 (and why)

- 7 voices (cost; 1–2 suffice), ambient mixer (polish not proof), widgets (native effort), speech recognition (permission friction), long Learn library (V1.1), vision board (retention feature, not activation), chat (scope), Android (iOS ≈77% of new sub launches).

## PRODUCT DECISIONS logged here

1. Gratitude promoted from Phase 2 (Aura plan) → minimal V1, because founder direction + near-zero build cost + memory-feed value. Full weaving stays V2.
2. Technique education enters V1 as _inline_ framing inside the Affirmation Studio only; standalone Learn tab deferred to V1.1 to protect scope.
3. Everything generated in V1 is server-generated (no on-device AI); audio cached; favorites replayable offline.
